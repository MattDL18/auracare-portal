# AuraCare - Government Social Benefits Portal

![AuraCare Portal](images/logo.png)

## 📌 About The Project

AuraCare is a prototype for a fictional government social protection and citizen assistance portal. It provides citizens with a centralized platform to discover financial assistance programs, check eligibility requirements, and submit fictional benefit claims entirely digitally.

This project was built from scratch to demonstrate strong fundamental web development skills without relying on external libraries or frameworks.

### ✨ Features
* **Zero-Framework Architecture:** Built entirely with pure, vanilla HTML5 and CSS3. No Bootstrap, Tailwind, or JavaScript libraries were used.
* **Semantic HTML:** Fully accessible and semantically structured markup (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<form>`).
* **Responsive Design:** Utilizes CSS Flexbox and media queries to ensure a seamless experience across desktop, tablet, and mobile screens.
* **Multi-Page Routing:** Seamless navigation across 4 interconnected pages with an active state visual indicator.
* **Accessible Forms:** Comprehensive HTML5 forms utilizing varied input types, fieldsets, and native browser validation.

## 🛠️ Built With
* **HTML5**
* **CSS3** (Flexbox, Custom Layouts, Pseudo-classes)
